# 🚀 STP - Ultimate Study Tracker App

A powerful, offline-first productivity application designed to help students track study hours, analyze consistency, and gamify their learning progress. Built with **React Native** and **Expo**.

## 📱 Features

- **⏱️ Real-Time Tracking:** Independent stopwatches for multiple subjects with daily 5 AM auto-reset logic.
- **📊 Analytics Dashboard:** Interactive Line Charts for history and Progress Rings for goal tracking.
- **📅 Heatmap Calendar:** GitHub-style contribution graph to visualize daily study intensity.
- **🏆 Gamification:** Dynamic ranking system (Subject-wise & Category-wise) with Gold/Silver/Bronze badges.
- **💾 Data Persistence:** Full offline support using Async Storage (data survives app restarts).
- **📝 Note Taking:** Add specific notes and syllabus details for every subject.
- **🌗 Dark Mode:** Fully adaptive UI for late-night study sessions.

## 🛠️ Tech Stack

- **Framework:** React Native (Expo SDK 52)
- **Language:** TypeScript
- **State Management:** React Context API
- **Storage:** Async Storage
- **Visualization:** React Native Chart Kit & Calendars
- **Navigation:** React Navigation (Tabs)
